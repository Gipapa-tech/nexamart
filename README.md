# Nexamart

A lightweight marketplace storefront built with Next.js, TypeScript, and Tailwind CSS.

Features included:
- Homepage with hero, categories, and featured products
- Product listing page and dynamic product detail page
- Shopping cart summary page
- Seller dashboard page
- Marketplace content geared to Nexamart's multi-seller model

Getting started:
1. npm install
2. npm run dev
3. Visit http://localhost:3000

This version focuses on the storefront and next-stage shopping experience for a beginner-friendly marketplace prototype.
