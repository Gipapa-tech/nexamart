# Nexamart

A marketplace storefront built with Next.js, TypeScript, and Tailwind CSS.

Included pages:
- Home
- Product listing
- Product detail
- Cart
- Checkout
- Login
- Sign up
- Seller dashboard
- Admin dashboard

Run locally:
1. npm install
2. npm run dev
3. Visit http://localhost:3000

This milestone adds the account and transaction flows needed to move from a storefront mockup into a more realistic marketplace experience.
